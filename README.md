# Sales Performance Dashboard

## Overview
This project builds a sales performance dataset and dashboard-ready analysis for tracking revenue, products, regions, sales representatives, and lead sources.

## Tools Used
SQL, Python, Power BI-ready CSV, Excel

## Key Deliverables
- Sales performance dataset
- Monthly revenue summary
- SQL KPI queries
- Monthly sales trend chart

## Business Questions
1. Which product categories drive the most revenue?
2. Which lead sources produce the highest-value customers?
3. How does monthly revenue trend over time?

## Resume Bullet
Built a sales performance dashboard using SQL and Power BI-ready data to track monthly revenue, product performance, lead source effectiveness, and regional sales KPIs.
